## English

### Overview

This repository contains custom Claude Code skills designed to enhance your development workflow. Each skill is a self-contained module that can be installed and used independently.

### Available Skills

| Skill | Description |
|-------|-------------|
| [clip](./clip/) | Collect, organize, and manage web articles, tutorials, news, opinions, and other online content |

### Installation

1. Clone this repository:
   ```bash
   git clone <repository-url> ~/.claude/skills/
   ```

2. Or clone individual skills to your skills directory

### Usage

Skills are automatically available in Claude Code once installed. Use slash commands or natural language to invoke them.
