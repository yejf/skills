# 观点评论模板

## 分类特征

观点文章通常包含：第一人称叙述、立场表达、论证结构、疑问句/判断句标题。

## 输出模板结构

```markdown
## 一句话概括

[作者的核心立场]

## 核心论点

### 论点1: [论点名称]

**立场**：[作者的观点]
**论据**：
- [论据1]
- [论据2]

**逻辑链**：[从论据到结论的推理]

### 论点2: [论点名称]
...

## 论证结构

```
前提 → 推理 → 结论
```

[描述作者的论证逻辑]

## 反面观点

**反方立场**：[反对者的观点]
**反方论据**：[反对者的理由]
**作者回应**：[作者如何反驳]

## 前提假设

[作者论证中隐含的前提假设]

## 金句

> 「最有冲击力的观点表达」
> —— 原文位置：文章第X部分

> 「论证中的金句」
> —— 原文位置：文章第X部分

## 个人评价

**同意的部分**：[哪些观点有道理]
**存疑的部分**：[哪些观点需要验证]
**延伸思考**：[可以进一步思考的方向]

## 标签

[话题] [立场] [领域]
```

## 提炼规则

### 必须提取
- 核心立场（一句话）
- 每个论点和论据
- 论证逻辑链
- 反面观点（如有）
- 隐含的前提假设

### 可以忽略
- 过多的修辞和铺垫
- 重复强调的观点
- 情绪化表达（除非是论证的一部分）

### 金句选择
优先选择：
- 立场表达最精炼的句子
- 反直觉的观点
- 论证中的关键转折
- 有启发性的总结

## 质量检查

- [ ] 核心立场是否清晰？
- [ ] 论证逻辑是否完整？
- [ ] 反面观点是否公正呈现？
- [ ] 前提假设是否识别？
- [ ] 金句是否忠实原文？
