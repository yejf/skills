# 提炼质量标准

## 核心原则

**增量价值**：提炼不是翻译或摘要，必须提供原文没有的结构化价值。

**忠实原文**：金句、数据、观点必须忠实于原文，不歪曲、不夸大、不遗漏关键条件。

**可追溯**：所有引用必须可追溯到原文位置。

---

## 通用质量规则

### 1. 金句提取规则

**必须遵守**：
- 金句必须是原文逐字引用，不翻译、不改写、不省略关键上下文
- 每条金句标注在文中的大致位置（开头/中间/结尾）
- 金句长度：20-150 字为宜，过短无意义，过长失去冲击力
- 每篇文章提取 3-5 条金句

**金句选择标准**：
- 表达精炼、有记忆点
- 代表文章核心观点
- 有独立引用价值（脱离原文仍能理解）
- 避免断章取义

**金句格式**：
```markdown
> 「金句原文内容」
> —— 原文位置：文章第X部分
```

### 2. 观点标注规则

**必须区分**：
- **原文观点**：作者明确表达的观点，标注为 `[原文观点]`
- **提炼推断**：从内容中推导出的结论，标注为 `[提炼推断]`
- **事实陈述**：客观事实，无需标注

**格式**：
```markdown
- [原文观点] 作者认为 X 是未来的趋势
- [提炼推断] 结合作者的论述，可以推断 Y 将受到影响
```

### 3. 数据引用规则

- 引用数据必须包含原文的限定条件（样本量、时间范围、来源）
- 数据必须标注出处（文中原图/表格/引用）
- 不要将个案数据泛化为普遍结论

### 4. TL;DR 规则

**何时需要**：文章超过 3000 字时必须有 TL;DR
**格式**：一句话概括，不超过 80 字
**位置**：正文开头，一句话总结之后

### 5. 标签提取规则

- 每篇文章 3-5 个标签
- 标签应反映文章主题，而非具体内容
- 优先使用已有标签体系中的标签
- 标签格式：小写英文，多词用连字符（如 `machine-learning`）

## 质量检查清单

完成提炼后，逐项检查：

### 内容完整性
- [ ] 一句话总结是否准确反映文章核心？
- [ ] 核心内容是否覆盖文章主要观点？
- [ ] 金句是否忠实于原文？
- [ ] 是否遗漏了文章的关键信息？

### 格式规范性
- [ ] frontmatter 字段是否完整？
- [ ] 分类是否正确？
- [ ] 标签是否合适（3-5个）？
- [ ] 阅读时间估算是否合理？

### 增量价值
- [ ] 提炼是否比原文更易读？
- [ ] 是否提供了结构化的信息组织？
- [ ] 金句是否有独立引用价值？
- [ ] 行动启发是否具体可执行？

### 忠实性
- [ ] 金句是否逐字引用？
- [ ] 数据是否包含限定条件？
- [ ] 观点是否标注了来源（原文/推断）？
- [ ] 是否避免了断章取义？

---

## 质量等级

完成提炼后，自评质量等级：

**A 级（优秀）**：
- 所有检查项通过
- 金句精炼有冲击力
- 提炼有明显增量价值
- 可以直接分享给他人

**B 级（良好）**：
- 核心检查项通过
- 金句准确但可能不够精炼
- 提炼有基本价值
- 需要少量修改才能分享

**C 级（及格）**：
- 基本检查项通过
- 金句可能有遗漏或不准
- 提炼价值有限
- 需要较多修改

**D 级（不及格）**：
- 多项检查未通过
- 需要重新提炼

## 常见质量问题

### 问题 1：金句翻译或改写
**错误**：将英文金句翻译成中文
**正确**：保留原文语言，可在括号内提供参考译文

### 问题 2：断章取义
**错误**：截取句子的一部分，改变原意
**正确**：保留完整句子，必要时保留前后文

### 问题 3：过度推断
**错误**：从个别案例推导出普遍结论
**正确**：明确标注推断的依据和局限

### 问题 4：信息遗漏
**错误**：忽略文章的关键限制条件
**正确**：在提炼中保留重要的限定条件

### 问题 5：缺乏结构
**错误**：简单罗列原文段落
**正确**：按逻辑重新组织，提供结构化视图
