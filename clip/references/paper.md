# 学术论文模板

## 分类特征

学术论文通常包含：作者机构、摘要(Abstract)、关键词(Keywords)、引言(Introduction)、方法(Methods)、结果(Results)、讨论(Discussion)、参考文献(References)。

与 `research` 分类的区别：
- `research`：研究报告、行业白皮书、基准测试
- `paper`：正式发表的学术论文、会议论文、期刊文章

```bibtex

  journal={Journal},
  year={2024}
}
```

## 标签

[研究领域] [方法] [关键词]
```

## 提炼规则

### 必须提取
- 研究问题和动机
- 核心贡献（不超过 3 点）
- 方法概述（不需要过于技术细节）
- 关键结果（保留数据）
- 局限性

### 可以忽略
- 详细的数学推导
- 完整的文献综述
- 实现细节（除非是核心创新）
- 附录内容

### 金句选择
优先选择：
- Abstract 中的核心结论
- Introduction 中的问题定义
- Discussion 中的洞察
- 对未来方向的展望

## 质量检查

- [ ] 研究问题是否清晰？
- [ ] 核心贡献是否准确提取？
- [ ] 方法是否简明描述？
- [ ] 关键数据是否保留？
- [ ] 局限性是否完整？
- [ ] 引用格式是否正确？
