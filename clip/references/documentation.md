# 官方文档模板

## 分类特征

官方文档通常包含：API 参考、配置说明、使用指南、版本信息、代码示例。

与 `tutorial` 分类的区别：
- `tutorial`：面向任务的分步指南
- `documentation`：面向参考的 API 文档、配置文档

## 提炼规则

### 必须提取
- 核心概念和定义
- 关键 API 的参数和返回值
- 配置项说明
- 使用场景
- 注意事项和限制

### 可以忽略
- 安装步骤（除非有特殊配置）
- 基础概念解释（除非是项目特有）
- 版本历史的详细记录

### 金句选择
优先选择：
- 最佳实践建议
- 重要的注意事项
- 设计决策的解释
- 性能优化建议

## 质量检查

- [ ] 版本号是否标注？

- [ ] 代码示例是否保留？
- [ ] 配置项是否准确？
- [ ] 注意事项是否提取？
