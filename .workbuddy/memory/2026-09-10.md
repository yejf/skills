## clip 技能 v2.4.0 — 管理界面迁移到资料库

用户需求：clip 剪藏技能需要一个统一界面管理不断增长的文章，讨论后确定资料库数据页方案（数据与视图分离），否决了"数据内嵌 HTML"方案（第一性原理：数据层与展示层必须解耦）。

最终方案（用户确认三点：每次剪藏增量写入资料库表 / 删除本地 collect.html / 改造范围按建议）：

- `templates/collect.html.template`：XHR 读 CSV → `__SMART_PAGE__.database` 只读 SDK（loadAll 翻页拉全量、onUpdated 订阅自动刷新、FIELD_MAP 占位符、DOM API 渲染替代 innerHTML——Write 工具安全钩子拦截 innerHTML 拼接，改用 createElement/textContent）
- `SKILL.md`：5.3 改为"同步到资料库"；存储结构、数据流、报告文案同步更新；版本 2.3.0 → 2.4.0
- 新增 `references/library-sync.md`：首次引导（import_csv 路径 A → node-info 取 spaceId → 校验真实 schema → 渲染模板替换占位符 → import_html --parent-id 挂为 CSV 节点子节点 + --databases 登记关联）+ 每次增量同步（batch_add_database_records，按真实字段类型构造 PropertyValue）+ 失败降级（不阻塞本地、只补写失败行）

关键知识点（来自 WorkBuddy 资料库技能）：
- import_csv 路径 A 返回的 node_block_id 即 SDK 的 databaseId
- import_html `--parent-id` + `--space-id` 必须同时传；`--databases` 顺带登记 page↔database 关联
- SDK query 单次只回一页（上限 200），拉全量必须 loadAll 循环，游标入参固定 `startCursor`
- file:// 下 XHR 被浏览器 CORS 拦截，本地静态页无法读相邻数据文件——本地管理界面此路不通
